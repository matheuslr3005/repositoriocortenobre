# Corte Nobre

Landing page de barbearia — página única, responsiva, em HTML/CSS/JS puro.

## Estrutura

- `index.html` — conteúdo e estrutura da página
- `style.css` — estilos e responsividade
- `script.js` — menu mobile, scroll do header e formulário de contato

## Como visualizar

Abra `index.html` diretamente no navegador, ou sirva a pasta com qualquer servidor estático:

```bash
python3 -m http.server 8000
```

Depois acesse `http://localhost:8000`.
